# StockVision

> Assistant intelligent pour la mise en rayon en grande distribution.

StockVision est un projet personnel visant à améliorer et simplifier le travail des employés chargés de la mise en rayon.

L'objectif principal est de permettre à un employé de **retrouver rapidement un produit dans un magasin**, grâce à une application capable d'indiquer précisément où celui-ci se trouve.

## 🎯 Objectif

Lorsqu'un employé doit mettre en rayon un produit, il peut parfois être difficile de savoir exactement où celui-ci doit être placé.

StockVision a pour objectif de fournir une solution permettant de :

- 🔎 Rechercher un produit
- 📷 Scanner un produit
- 📍 Localiser précisément le produit dans le magasin
- 🗺️ Afficher son emplacement sur une carte intérieure du magasin
- 🧭 Guider l'employé jusqu'à son emplacement
- 📦 Gérer des listes de produits à mettre en rayon
- 🚶 Optimiser le parcours pour plusieurs produits

À terme, le projet pourrait également intégrer de la **réalité augmentée**, afin d'afficher directement les indications de navigation dans des lunettes connectées.

## 🧠 Vision

L'idée à long terme est de transformer StockVision en un véritable assistant de mise en rayon.

Par exemple :

```text
Employé
   │
   ├── 📷 Scanne un produit
   │
   ▼
StockVision
   │
   ├── 🔎 Identifie le produit
   ├── 📍 Trouve son emplacement
   └── 🗺️ Calcule le chemin
   │
   ▼
Navigation dans le magasin
   │
   ▼
📦 Emplacement du produit
```
